# Анализ требований: Создание бронирования (POST /booking)

В данном документе собраны пробелы в документации к API и вопросы, которые необходимо уточнить у аналитика перед началом тестирования.

| Поле | Что сказано в документации | Что не сказано | Вопрос аналитику |
| :--- | :--- | :--- | :--- |
| **firstname** | Тип `string`, Имя гостя, оформившего бронирование | Максимальная длина? Минимальная длина? Допустимы ли цифры, пробелы, эмодзи? Пустая строка? Допустима ли кириллица, спецсимволы? Обязательность заполнения. | Какие ограничения у имени? |
| **lastname** | Тип `string`, Фамилия гостя, оформившего бронирование | Максимальная длина? Минимальная длина? Допустимы ли цифры, пробелы, эмодзи? Пустая строка? Допустима ли кириллица, спецсимволы? Обязательность заполнения. | Какие ограничения у фамилии? |
| **totalprice** | Тип `number`, Общая стоимость бронирования | Какая валюта? | Может клиент оплачивать другой валютой? |
| **depositpaid** | Тип `boolean`, Выплачен ли депозит или нет | *(Всё описано)* | *(Нет вопросов)* |
| **checkin** | Тип `date`, Дата заезда гостя | Может гость заехать в прошлом? Допустимы буквы? Какой формат даты? Может ли гость выбрать сегодняшний день? Спецсимволы, пробелы, эмодзи, пустая строка? Обязательность заполнения. | Какие ограничения у даты? |
| **checkout** | Тип `date`, Дата выезда гостя | Может гость выехать в прошлом? Допустимы буквы? Какой формат даты? Может ли гость выбрать сегодняшний день? Спецсимволы, пробелы, эмодзи, пустая строка? Какой лимит по времени (ограничению на 1 бронирование)? Обязательность заполнения. | Какие ограничения у даты? |
| **additionalneeds** | Тип `string`, Любые другие потребности гостя | Минимальная/максимальная длина, пустая строка, обязательность заполнения? | Какие требования к полю "дополнительная потребность"? |
